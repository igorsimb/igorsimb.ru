02 / Working with AI

How I work with coding agents.

I use coding agents for implementation and tests. I decide the approach, review every change, and ask for an explanation when I do not understand something.

  1. 01I planI define the problem, constraints, and tradeoffs.
  2. 02We brainstormAgents help me explore options before I choose an approach.
  3. 03AI implementsAgents write code and tests against the agreed plan.
  4. 04We reviewA separate reviewer agent checks the implementation first. I then review every change myself and stop when I cannot explain it.
  5. 05I verifyI run the relevant checks and take responsibility for the result.
